Release v0.15.2

Release v0.15.2 — Workspaces everywhere, no-flag Artifacts, and a rebuilt model picker

### New
- One workspace replaces projects and accounts on every surface, with the workspaces database split behind it. (#11857)
- Artifacts need no flag, and artifact comments are removed. (#11963)
- Notifications are on for every project, with an Inbox page; the Inbox later joins the workspace menu. (#11959, #11986)
- Web patterns and design-system guidance are standardized across the app. (#12031)
- Settings get a drill-down sidebar with deep search and a 7-row workspace menu. (#12077)
- One model picker with favorites, provider tabs and thinking levels. (#12116)
- Connect ChatGPT and Connect Claude sit on the project home, unified into one connect-a-model surface. (#12111, #12115)
- Customize is Workspace settings, Review joins the Inbox, and Skills loads without a kortix.yaml. (#12120)
- Onboarding: a workspace with no runnable agent blocks the chat area, and existing repos get a one-click setup prompt. (#12095)
- The upgrade modal's plan view matches the /pricing plan band. (#12110)
- The activation funnel splits invited from self-serve signups and counts every first prompt. (#12034)
- Trigger rows truncate long names and count down to the next run. (#11972)
- The agents' decision on a workflow: My Kortix starts one only for many-part work or when asked. (#12036)

### Improved
- Session-log reads are bounded by bytes, and kortixd stops digesting the whole log per poll. (#12090, #12071)
- Drive conflicts open in a static bottom-right popover with no grow animation, and a test covers it. (#12112, #11042)
- The upgrade modal no longer scrolls sideways at high credit tiers. (#12114)
- The hero walkthrough survives a throwing step timeline. (#12093)
- A session's My Kortix tool steps stay in the chat and never show the agent's instructions. (#12113)
- A tool call clicked in the chat never opens an empty right panel, and an agent row with a non-string slug renders a label instead of crashing. (#12055, #12088)
- Vercel stops building the frontend on every push, and `pnpm dev`/`worktree start` decrypt through the Armor login again. (#12058, #12037)
- Slow daemon reads carry the daemon's loop lag in the cause. (#12053)
- The landing hero drops the four-trait line above the title. (#12119)
- Kortix Cloud no longer offers account branding. (#12096)
- An inline agent hand-off row reads "Inline" instead of "General". (#12127)
- The needs-input badge poll keeps out of error toasts and Sentry. (#11952)

### Security
- Open repository advisories are closed (Bun Brotli, tunnel, Apps, Firecrawl, asks). (#12082)
- The edge contract answers 405 with Allow and forces HTTP→HTTPS with 308. (#11707)
- The Platinum sandbox webhook keys its replay guard on the delivery identity. (#12084)
- git-proxy GET routes authenticate before query validation. (#11997)
- Connector calls with an empty path argument are denied before the upstream call. (#12105)
- Selecting a session provider-secret pool requires project.secret.read, and public OpenAPI operations are marked with security: []. (#12063, #12009)
- The public trigger webhook body is bounded before the signature check. (#12062)
- The gateway playground never echoes a database error's message. (#11995)
- The test-environment gate lets security.txt through. (#11967)
- Leaked credentials are revoked same day, and CI never uses a Cloudflare Global API Key. (#12083)
